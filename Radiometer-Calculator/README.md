# Radiometer Calculator — מחשבון שטף פוטוני

מחשבון שמחשב את **השטף הפוטוני** (Photon Flux) הנפלט מסנטימטר מרובע אחד
של חומר הנמצא בטמפרטורה `T`, בתוך תחום אורכי גל נתון `[λ₁, λ₂]`.

## הנחות
- החומר מתנהג כגוף שחור עם כושר פליטה (emissivity) **ε = 1**.
- הפליטה היא לחצי כדור (hemispherical) — נעשה שימוש בעקומת פלאנק
  האינטגרלית על כל הזוויות (מקדם π כלול).

## הפיזיקה
חוק פלאנק לעוצמת הפליטה הספקטרלית (הספק ליחידת שטח ליחידת אורך גל):

```
M_λ(λ,T) = (2πhc² / λ⁵) · 1 / (exp(hc / λkT) − 1)        [W / m² / m]
```

אנרגיית פוטון בודד: `E = hc / λ`. לכן השטף הפוטוני הספקטרלי:

```
N_λ(λ,T) = M_λ / E = (2πc / λ⁴) · 1 / (exp(hc / λkT) − 1)  [photons / s / m² / m]
```

והשטף הכולל בתחום מתקבל מאינטגרציה:

```
Φ = ∫_{λ₁}^{λ₂} N_λ(λ,T) dλ                                [photons / s / m²]
```

לבסוף ממירים לסנטימטר מרובע (`1 m² = 10⁴ cm²`).
האינטגרל מחושב נומרית בשיטת **סימפסון**.

## הרצה
```bash
python3 radiometer.py
```
הקלט: טמפרטורה בקלווין, ותחום אורכי גל בננומטר (nm).

דוגמה — חומר ב-300K בתחום ה-IR התרמי 8–14 µm:
```
טמפרטורה [קלווין]: 300
אורך גל התחלתי [nm]: 8000
אורך גל סופי [nm]: 14000
→ שטף פוטוני: 9.45e+17 photons / s / cm²
```

## שימוש כספרייה
```python
from radiometer import photon_flux

# טמפרטורה בקלווין, אורכי גל במטרים
flux = photon_flux(300.0, 8e-6, 14e-6)   # photons / s / cm²
```

## אימות
השטף הפוטוני הכולל של גוף שחור (אינטגרציה על כל אורכי הגל) שווה לקבוע הידוע
`1.5204 × 10¹⁵ · T³` photons/s/m². הבדיקה הנומרית מתכנסת לערך זה ברמת דיוק של
‎~99.96%‎.
